# 实验四 JAR 包使用说明

所有 JAR 包均在集群节点执行，通过平台拼接命令提交。输入数据位于 HDFS 的 `/user/root/Exp4/` 目录，请确保输出路径在执行前不存在。

---

## 任务一：统计喜欢相同电影的用户
- **主类**：`Task1`
- **JAR 包**：`Task1.jar`
- **参数**：输入路径、输出路径  
  输入为完整的评分数据 `ratings.csv`，输出即为 `A-B  N` 格式的结果。内部包含两个串行 MapReduce 作业，会生成临时目录（位于输出父目录下的 `task1_tmp`），结束后可手动删除。

---

## 任务二：有相同喜好的用户
- **主类**：`Task2FromTask1`
- **JAR 包**：`Task2FromTask1.jar`
- **参数**：任务一的输出目录、任务二的输出路径  
  读取任务一结果，生成每个用户的同好列表，格式为 `用户ID:好友1,好友2,...`，列表内按数值升序排列。仅包含一个 MapReduce 作业。

---

## 任务三：统计电影热度
- **主类**：`Task3`
- **JAR 包**：`Task3.jar`
- **参数**：评分数据路径、输出路径  
  通过 `-files hdfs:///user/root/Exp4/top100.csv#top100.csv` 将热门电影列表注入缓存，统计每部电影喜欢人数，输出格式为 `电影ID:人数`。仅一个 MapReduce 作业。

---

**注意事项**：  
- 执行前务必删除已存在的输出目录（任务一还需删除同级的 `task1_tmp`）。  
- 任务三必须使用 `-files` 参数指定缓存文件，且别名 `#top100.csv` 不可省略。  
- 各作业成功后可在 YARN WebUI 查看执行报告。
